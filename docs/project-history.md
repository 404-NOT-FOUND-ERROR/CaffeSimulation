## 当前摩卡工作台

从 **http://127.0.0.1:4186/studio.html** 进入：先选随机来单或自由创作，再选摩卡壶。旧摩卡准备和冲煮地址会转入 `moka.html`。手冲与意式仍为早期原型。

2026-10-04 根据体验反馈改为“选择与观察”，不再要求用户学习拧盖、拖水壶或瞄准粉篮的手势。

- 进入后自动打开冷壶。左侧剖面始终显示水位、粉层、导管与安全阀；点选对应部位即可查看说明，结构展开按需使用。
- 水位直接在左侧下壶剖视上拖动圆点调节，水面、实际用量与模型即时同步；“建议水位”自动演示实际加入，完成前不能进入下一步。超过安全阀下缘时标红，冲煮被阻止，可直接向下调回，其他原料保留。
- 左侧准备区将剖视、控制、用量与说明放在一起。水位页使用按生图概念重绘的 SVG 金属下壶、内腔、水面、空气空间和安全阀；装粉页展示粉篮断面及研磨颗粒。水位和粉篮使用不同镜头，当前无关器具淡出，建议量用离散颗粒或水流演示，不要求操纵水壶或拧盖。
- 选择研磨与装满粉篮后，开始冲煮会连续演示粉篮落位、扫净壶缘、旋合和手柄移炉。自动动作期间暂时锁定配方，避免动画和材料状态冲突。
- 火力滑杆保留实际决定：可以减火、停火、继续未完成的冲煮。剖面同步下降水位、上升咖啡液，并显示经过粉层与中央导管的水路。出液结束自动关火。
- “关火，倒入杯中”连续演示关火、手柄移壶和倾倒。咖啡质量与溶质转移守恒。关火、调饮和海报不会令金属立即冷却，提示持续到真实模拟冷却。
- 调饮是可回改的虚拟配方编辑：牛奶、水和冰的量分别调整，杯子同步更新颜色与液量。总量上限 350 g，不改变咖啡基底；不自动增加奶泡、拉花或 crema。
- 特刊仍使用实际成杯生成报道：3 种构图 × 6 种独立配色、标题编辑、拖动构图和 1200 × 1800 PNG 导出。最近成杯回存工作室。
- “保留这一杯，再做一锅”换用冷壶和新原料。清洗当前提供说明，尚未制作倒渣、冲洗和晾干动画。

场景使用本地 Three.js 与 `assets/moka-silver-v2.glb`，保留源 `blenderco_cn.blend`。补充实体内腔、漏斗、滤网、安全阀、杯子与工具。当前灯光使用面向器具的柔光反射板、方向光、柔和接触阴影和中性银色铝材质。

`workshop-state.mjs` 负责材料、热状态和出液守恒；`workshop-controls.mjs` 负责用量选择与配方修订；`workshop-cutaway.js` 与 `workshop-cutaway-details.js` 绘制可交互 SVG 剖视；`preparation-motion.mjs` 定义上壶连续开合路径及水位坐标；`workshop-scene.js` 负责模型和镜头；`workshop-experience.js` 连接选择、自动演示、说明和特刊。原 `workshop.js` 为上一版手势原型，不再被页面加载。

教学内腔与容量尚未按实物核验，加热时间压缩、流量未经实测标定，颜色不能预测风味。安全阀下缘、装粉不压实、小火、热表面与充分冷却等规则参考 Bialetti 官方说明，实物以具体器具说明为准。

水位圆点支持方向键（5 g）、Shift + 方向键（1 g）与 Home/End；其余滑杆支持键盘操作，剖面热点支持 Tab 和 Enter。结构展开暂停制作并保留原料、温度与配方，收起后继续。页面恢复保存原料与进度，重新加载不会恢复明火。

`package.json` 的测试脚本涵盖连续开合路径、剖视坐标、用量调整、越界修正、热状态、守恒与配方快照。当前细化验收见 `docs/preparation-refinement-acceptance.md`，实际页面截图见 `qa/refined-preparation-*.png`。设计概念保存于 `assets/concepts/water-cutaway-concept-01.png`，完整生图提示词见 `docs/water-cutaway-concept-prompt.md`。此前 `qa/hands-on-*` 和 `qa/choice-*` 保留为上一版记录。


## 原摩卡实验室

根页面与原章节入口保留，以下为原实验室的逻辑与验证说明。

## 体验逻辑

四个章节共用同一套操作框架，首次打开直接进入自由冲煮，前面三章可以随时探索。

1. **拆开与组装**：拖动旋转、控制展开程度、点选六个零件，理解各自作用，提出关于水向上走的猜想。
2. **水的路线**：分三段观察液态水进入细管、穿过粉层、经过滤网与上壶导管。采用明确的结构示意图，避免把视觉效果当作真实流场。
3. **加热与压力**：改变加热强度、播放或拖动演示进程，观察气体与相对压力变化。
4. **自由冲煮**：选择饮品目标，调整研磨度、加热强度和教学水量；运行、暂停、提前结束或快速拖动。对照、线索、调饮都在这个章节内部。

自由冲煮形成循环：**设置 → 冲煮 → 观察 → 保留对照 / 排查线索 → 再试 → 调饮 → 海报**。

对照保存上一锅的独立记录，新一锅只改变研磨度或加热强度，水量与粉量保持一致。两条曲线比较累计出液。诊断有接缝异常与流路阻力异常两种虚拟案例，观察热点并判断原因，正确后再试。

调饮保留咖啡基底的质量与已溶出的成分，选择原液黑咖、加水黑咖或摩卡奶咖，按质量添加水或牛奶。咖啡液占比与萃取不是同一个量；加奶后不把咖啡成分浓度当作饮品总 TDS。

## 海报系统

分享海报允许多种版式与配色，独立于实验室的暖铜视觉。首版有透视大字、晨光拱形、字体海报三个版式，以及奶油铜、都灵蓝、柠檬绿、朱红夜、夜咖蓝、玫瑰棕六组配色，共 18 种组合。以后继续扩展形状、人物、杯型与场景。

切换版式和配色只改变表达，不改变饮品与配方。可编辑标题，选择是否保留配方与知识提示，导出 1200 × 1800 PNG。复现链接编码冲煮设置、结束进程、饮品、配比、标题与海报样式，重新载入可还原结果。当前服务地址是本机地址，图片可直接分享；链接要接入正式平台后才能供他人访问。

## 第一版的实现边界

- 界面是 HTML/CSS，壶是由 Three.js 加载的 GLB 外观模型及补充内部件，水路与气体采用 SVG，成杯和海报采用 SVG / Canvas。没有用整张生图替代按钮和模型。
- 摩卡壶外观基于用户提供的 `blenderco_cn.blend`。当前版本按概念图改为银色铝壶与黑色手柄、顶钮：外壳增加微小倒角和加权法线，手柄改为带圆角的折线轮廓，加入微细表面粗糙度以及摄影棚反射。补充连续螺纹、可透过的滤孔、金色安全阀和咖啡粉颗粒。细化后的外壳 GLB 约 252 KiB，原 Blender 文件保留原样。
- 各零件沿同一根轴拆开，整体保持倾斜构图。原文件以外观展示为主；内衬、粉篮、滤网、密封圈、导管及安全阀是补充的教学结构，不是原资产的真实内部 CAD。导出时只打开外壳端面，未改变原文件。
- 冲煮数据是可重复的定性教学模型，尚未按真实器具、咖啡豆、粉量和温度测量校准。演示进程不是实际分钟，压力是相对量。固定粉量 18 g 是模型内部预设，不是跨器具适用的冲煮建议。
- 不评价真实风味优劣，不输出精确口感分数；摩卡咖啡不标为意式浓缩，未模拟 crema。
- 首版验证探索闭环、状态一致性和设计可实现性。下一阶段需要接入经核验的真实模型与校准数据，并让不同参数的流速、出液和调饮视觉更丰富。
- 模型点击与旋转支持鼠标和触控，交互控件可用键盘。窄屏重排，海报预览可滚动。全部资源本地加载，无外部账号、上传和远程请求。

## 运行

在此文件夹执行 `node serve.cjs`，打开 http://127.0.0.1:4186。也可运行 `start.ps1`，它先查系统 Node.js，再使用当前 Codex 的本地 Node.js。

验证：`node qa/model-test.mjs` 检查 81 种冲煮状态的单调积累、质量守恒与调饮守恒。`qa/browser.cjs` 使用本机 Edge 和 Playwright 检查章节、3D、对照、诊断、调饮、18 种海报组合、PNG 导出、链接复现和手机布局；截图保存在 qa 文件夹。`qa/refinement-check.cjs` 检查 100%、125%、150%、200% 像素比、20 次窗口尺寸切换、实际全屏进入/退出及手机布局。

## 全屏尺寸修复

修复前，125% 像素比下，画布 CSS 高度在连续五次采样中从 779 px 增加到 899 px。画布作为普通文档元素参与父级 flex 尺寸计算，渲染分辨率更新后产生布局反馈；监听画布又触发下一次更新。现在画布绝对定位在独立容器中，只监听容器的 CSS 尺寸，尺寸或像素比确实变化时才更新渲染缓冲；相机同时按模型包围盒和可用宽高留出边距。放大窗口不会继续累积放大模型。显示尺寸与渲染尺寸的区分也可参见 [Three.js 响应式渲染说明](https://threejs.org/manual/pages/responsive.html)。
