# 2026-10-09 · 摩卡混合工作台升级

## 采用的规划

首页接单或自由发挥，选器具，准备水与粉，冲煮同时认识结构，调配与双杯对照，最后制作特刊。采用已选的并行工作台方案：操作模拟在左，结构模型在右。知识是制作中的即时说明，不增加单独必经关卡。

## 实现

- 准备页只有加水 / 装粉两标签，均可回改。实际水面在安全阀下缘线以下，超过演示范围会阻止开始；18 g 是这把教学粉篮的容量示意。
- 自动装配沿模型共同轴运动，使用指数缓动；不提供单件任意移动、螺纹拖拽或自由倾倒。二维已组装壶放在炉头；右边标注为冷态教学模型，不把拆开的器具放在火上。
- 左剖面水位下降、上壶液位升高、中央管与水路随出液更新。更新已有 SVG 节点，避免每帧重建和动画重启。用户可关火及提前收取，查看组件不暂停制作。
- 右侧六组 GLB 使用有限观察角度和装配轴展开，相机按容器尺寸适配，画布不参与父元素尺寸反馈。采用 PMREM 环境反射、柔和明暗卡、金属微表面与不同零件的材料参数。
- Blender 中滤网改为真实通孔，修正上壶底圈与下壶颈部的金属重叠；外半径 .603、内半径 .61，径向间隙 .007。密封圈顶与座面均在 1.71。全展开六组相邻轴向包围盒间隔 .33 / .39 / .202 / .082 / .60001。
- 导出前统一闭合网格法线，并明确三角化凹形手柄面。上壶标签移到手柄外侧，避免背景遮住手柄。工作台使用 `overflow: clip`，避免底部按钮获得焦点时把内部顶栏滚出画面。
- 上壶最大半径 .91，下壶最大半径 .74；二维轮廓共用这些比例。组件不单独旋转，保持共同轴。GLB 约 1.5 MiB。
- 收取按实际质量生成批次，并幂等地接入调配库存。再次进入已收取锅不会重复造出咖啡。第二锅保留现有饮品，单独进入可选库存。
- 调配支持托盘连续添加、精确用量、撤销和选杯。分杯 / 合杯保留成分和批次记录；合杯超过演示杯 360 g 时拒绝。搅拌渐变使用 smoothstep 与连续波形，冰保留为固体；减少动画设置直接到终态。
- 杯子液位使用渐宽容器的面积积分近似；色带用于配方表达，成品为暖色混合视觉。奶泡和冰的真实密度、融化和液面体积并未求解。
- 特刊有三种真正不同的构图，六种配色；实际配方与来源进入报道，改构图不改饮品。人物图保持原比例，SVG 杯子与实时配方同源。

## 实际验收

通过 CUA 在本机浏览器操作，不通过脚本注入跳过制作：

- 首页来单和自由发挥均先进入器具选择，再进入摩卡工作台；器具选择页在 844×390 无横纵溢出。
- 水 120 g → 装满粉篮 18 g → 自动合壶、小火 → 实际收取 86.4 g。
- 第一次 40 g 入杯、46.4 g 留在库存；加水与冰后分成 A/B。B 加奶 60 g，A 保持 100 g，B 为 160 g，咖啡各 20 g。
- 再做一锅后上述两杯及第一批来源不变，新批次库存 86.4 g。
- 另一锅刚开始时点击滤网、上壶：进度从 0% 到 3%，火力仍为小火。查看结构没有冻结制作。
- 配方视图点搅拌：观察到 data-progress 0.081，约 2.8 秒后过渡节点消失并选中成品；冰块保留。
- 1366×768、844×390 主文档无纵向溢出；模型画布从 524×324 适配至 364×142，没有尺寸递增。390×844 竖屏自然滚动，无横向溢出。
- 浏览器未出现 WebGL 或 JavaScript 警告 / 错误。IAB 全屏按钮没有得到可确认的全屏状态，因此只确认窗口尺寸变化的稳定性，未把真全屏标记为已通过。
- 实际导出 1200 × 1800 PNG，核对 A 杯咖啡 20 g / 水 60 g / 冰 20 g，B 杯额外牛奶 60 g；图片已收入验收目录。十一组 npm test 通过，修改的十个模块语法检查通过。截图在 `qa/hybrid-review-2026-10-09/`。

## 科学依据与边界

[Bialetti 官方 Moka Express 使用说明](https://bialetti-cookware.zendesk.com/hc/en-us/articles/5416235346322-How-to-use-the-Moka-Express) 支持水低于安全阀、粉篮装满但不压实、火焰不超过壶底、出液结束移离热源等操作规则。

[维也纳大学摩卡壶研究入口](https://compphys.univie.ac.at/Moka/) 用作后续物理模型资料入口。本版采用压力差推动液态水穿过粉层的定性教学表达，没有宣称研究的数值校准。

几何包围盒、径向间隙与座面核对不等于全面三角网格碰撞验证或制造认证。加热过程经过压缩；虚拟自动关火明确区别于真实器具。没有 TDS、味觉或真实温压预测，也没有把用户未实际倒入的材料自动记入配方。
